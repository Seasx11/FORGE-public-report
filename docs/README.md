# FORGE documentation

Everything you need to use FORGE during the invited preview. FORGE runs in your browser; there is nothing to install or configure on your own computers.

These guides cover the hosted workspace that invited shops use today: customers, jobs, quotes and customer approval. The rest of the workspace shown in the [overview](../README.md) is rolling out to hosted accounts in stages, and these guides grow with it.
